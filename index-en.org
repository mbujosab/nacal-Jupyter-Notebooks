Each Notebook is a study guide for one section of the [[https://mbujosab.github.io/CursoDeAlgebraLineal/libro.pdf][book]]. It tells you which video to watch and what to read, and it proposes exercises to do on the computer with the Python module [[https://github.com/mbujosab/nacallib][NAcAL]]. NAcAL uses the same notation as the book and the lectures. The book is in Spanish.

The links in the tables open each Notebook in the browser with MyBinder. Nothing needs to be installed. MyBinder is a free service: it takes a moment to start and it sometimes fails. Further down you can read how to work on your own computer.

To try code from the book or from the slides there is a [[https://mybinder.org/v2/gh/mbujosab/nacal-jupyter-notebooks/master?urlpath=lab/tree/Eng/BlankNotebook-Eng.ipynb][blank Notebook]]. At the end it has a reminder of the most frequent commands.

* How to work on your own computer (recommended)

1. Install [[https://www.python.org/downloads/][Python]].
2. Install Jupyter and NAcAL. In a terminal: =pip install jupyterlab nacal=
3. Download the whole [[https://github.com/mbujosab/nacal-Jupyter-Notebooks][repository]], or only the Notebooks you want.
4. Open a terminal in the folder of the Notebooks and run =jupyter lab=. A browser window will open with the Notebooks.

If you only want to read the Notebooks, without running them, you can see them [[https://nbviewer.jupyter.org/github/mbujosab/nacal-Jupyter-Notebooks/tree/master/][here]].
