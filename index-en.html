Versión en español

Each Notebook is a study guide for one section of the book. It tells you which video to watch and what to read, and it proposes exercises to do on the computer with the Python module NAcAL. NAcAL uses the same notation as the book and the lectures. The book is in Spanish.

The links in the tables open each Notebook in the browser with MyBinder. Nothing needs to be installed. MyBinder is a free service: it takes a moment to start and it sometimes fails. Further down you can read how to work on your own computer.

To try code from the book or from the slides there is a blank Notebook. At the end it has a reminder of the most frequent commands.

Other course materials

  • The book of the course (in Spanish).

How to work on your own computer (recommended)

  1. Install Python.
  2. Install Jupyter and NAcAL. In a terminal: pip install jupyterlab nacal
  3. Download the whole repository, or only the Notebooks you want.
  4. Open a terminal in the folder of the Notebooks and run jupyter lab. A browser window will open with the Notebooks.

If you only want to read the Notebooks, without running them, you can see them here.
